# 🧮 Modern Scientific Calculator

A modern desktop scientific calculator built using Python and Tkinter.

The project provides a clean graphical interface with scientific
operations, calculation history, memory functions, keyboard support,
and Dark/Light mode.

---

## ✨ Features

### Basic Operations

- Addition
- Subtraction
- Multiplication
- Division
- Percentage
- Decimal calculations
- Parentheses

### Scientific Operations

- Square root
- Square
- Power
- Sine
- Cosine
- Tangent
- Logarithm
- Natural logarithm
- π
- e

### Memory Functions

- MC — Memory Clear
- MR — Memory Recall
- M+ — Memory Add
- M- — Memory Subtract

### Other Features

- 🧹 AC / CE
- ⌫ Backspace
- ± Positive/Negative
- 📜 Calculation History
- 🌙 Dark Mode
- ☀️ Light Mode
- ⌨️ Keyboard input
- Persistent calculation history
- Error handling

---

## 🖥️ Interface

The calculator provides a graphical user interface built using
